# VirtualWorld

Проект для отборочного этапа чемпионата «Профессионалы».
Компетенция: «Разработка виртуальных миров».

## Модуль А: Sweet Home 3D
- Проект здания по плану (2D и 3D).
- Мебель, материалы, экстерьер.

## Модуль Б: Unity
- Сцена с тремя зонами (гостиная, ванная, спальня).
- Игрок (Character Controller, MouseLook).
- Коллизии (стены, пол, потолок).
- Свет: Directional Light + 4 Point Light.
- Двери, открывающиеся по E.
- NPC с диалогом. (Собака: при нажатии E появляется «Гав!»).

## Что не успела:
- Полноценный сценарий с несколькими путями.
- Оптимизация (LOD, Lightmaps).
- Сборка .exe.
