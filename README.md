# VirtualWorld

Проект для отборочного этапа чемпионата «Профессионалы».
Компетенция: «Разработка виртуальных миров».

## Модуль А: Sweet Home 3D
- Проект здания по плану (2D и 3D).
- Мебель, материалы, экстерьер.

## Модуль Б: Unity
- 3 зоны: гостиная, ванная, спальня.
- Игрок (Character Controller, MouseLook).
- Коллизии (стены, пол, потолок).
- Свет: Directional + Point Lights + Lightmaps.
- Мебель и декор.
- Интерактив: двери, радио, собака, миска.
- NPC: собака с диалогом.

## Модуль В: Интеграция сценариев
- UI заданий (QuestPanel).
- Диалог с выбором (Иди на место / Пойдем кушать).
- Звук: радио

## Модуль Г: Оптимизация
- Static флаги.
- Lightmaps.
- Box Collider вместо Mesh Collider.
- Пост-обработка (Global Volume).
- Сборка .exe.
